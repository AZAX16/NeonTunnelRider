## Interpretations and unresolved external details

- Page 4 describes Bloom “from the Post-Processing package.” URP supplies integrated post-processing and does not support Post Processing Stack v2. This package implements the required visible Bloom through URP Volumes and explicitly documents that interpretation; do not install both stacks. No specific package identifier is named in HW2. If the instructor demands the old package literally, resolve that pipeline requirement before visual production.
- A hovercar is acceptable as a proposed car-shaped vehicle, not a PDF promise. Keep headlights, car-sized footprint, roadway and grounded lane behavior. A conventional wheeled visual can replace the mesh without changing mechanics if the instructor requires it.
- Student first name, last name, ID, accessible repository URL, target grader OS and course upload access are not supplied. Task 16 must resolve them; never fabricate final submission evidence.
- The PDF does not define a score formula. Distance points plus coin points is a design choice; both are visible and testable.
