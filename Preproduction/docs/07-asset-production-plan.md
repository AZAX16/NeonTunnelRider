# Asset production specification

Use low-poly reusable geometry and shared URP materials. Budgets below are starting targets for a desktop student project; measure on the user's actual Linux GPU before calling performance acceptable. The generated PNGs are **reference images**, not game-ready 3D assets. No mesh, rig, UV map, calibrated PBR set or collider is implied by an image.

All models: meters, +Y up, +Z forward, applied transforms, positive scale1. Keep runtime collision roots unrotated and separate from presentation motion. Import through Unity, verify scale/materials/normals/pivots, add colliders and pool lifecycle, then test at the actual chase-camera distance.

## Production steps and quality gates

1. Graybox every collider and module using primitives; prove seams, lane widths and pickup reachability before replacing meshes.
2. Model one player, two obstacle silhouettes, four modular road variants, one ring and one can. Reference images guide style; do not trace a branded car.
3. Use shared flat materials and an optional small trim atlas. Bake bevels only if needed; keep textures mostly512–1024px. Avoid costly transparent car glass: use opaque dark cyan Lit material.
4. For generated texture candidates, remove painted lighting, check tiling seams, validate color space, author independent normal/metallic/smoothness maps with correct semantics. An RGB image is not a measured normal map. Test material on a plane/cube before importing widely.
5. Create prefabs and pool reset hooks. Inspect mesh/collider mismatch, bounds, Z-facing and ride height, return/rent behavior, renderer material count and shadow cost.
6. Verify silhouettes at120m, all lanes at50m/s, Bloom on/off, low-fuel state and small-window HUD. Compare final gameplay to concept mood, not every painted reflection.

## Material and GPU budget

Start with ≤10 shared environment/vehicle materials, ≤250 visible draw calls, ≤150k visible triangles, one directional moon light (shadows optional), two headlight spots, one underglow light and ≤4 nearby nonshadowing streetlights. Use renderer light limits suitable for installed URP; emission strips need no real Light per strip. Avoid realtime reflection probes and fullscreen motion blur. These are tuning guardrails, not claims about delivered performance. If p95 frame time misses16.7ms, reduce decorative lights, particle overdraw and transparent layers before compromising required gameplay.

## Audio asset specification

Music: one60–90s seamless synth loop, stereo, licensed/original; engine: short seamless mono loop with no clicks; collision: .2–.5s metallic thud/spark; coin: .1–.2s bright chime; fuel: .25–.4s lower charging cue. Keep source WAV masters and recorded licenses; choose compressed music/loaded short SFX based on import profiling. Use mixer headroom; avoid normalizing every clip to the same loudness blindly. Image generation cannot provide these audio assets. Record simple original sounds or use clearly licensed sources and verify license terms individually before download.
