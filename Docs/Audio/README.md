# Task 13 original audio masters

Run `PYTHONDONTWRITEBYTECODE=1 python3 Docs/Audio/synthesize.py` from the Unity repository root with Python 3 and NumPy installed. No network, external samples, runtime synthesis or extra Unity package is used. The script writes deterministic 44.1 kHz, 16-bit WAV files and `Evidence/Task13/masters.json` with hashes, channel counts, duration, DC, RMS, peaks and adjacent loop-boundary sample differences.

VectorNight is an original 64-second / 32-bar composition at 120 BPM. Two bars each of Am, F, C and G repeat across four arrangement phrases; the second/fourth introduce a separate lead. Harmonic bass, arpeggio, pad, kick, snare and hats are synthesized. Circular delays wrap into the opening instead of cutting a reverb tail. HoverEngine is a 2-second periodic 55 Hz core with eight decreasing harmonics, 2 Hz phase modulation and 3/8 Hz amplitude modulation. All oscillator cycles fit the loop exactly; the boundary's nonzero adjacent-sample delta is the normal waveform slope, not an inserted zero pad. Impact is a .34-second shaped noise/metal/body transient; CoinChime is .18 seconds at 1318.51/1975.53/2637.02 Hz; FuelCharge is .34 seconds with a rising 220–440 Hz body and 660 Hz overtone. Short cues have tapered endpoints and zero-mean compensation. Peaks are normalized to .65, leaving headroom.

Unity imports music as stereo Streaming/Vorbis quality .8 and short clips as mono DecompressOnLoad/PCM. Sample rate is preserved; preload is enabled, background loading is disabled. Engine PCM prevents codec padding at its repeated seam. Loops are controlled by the two authored AudioSources, not WAV metadata. See the verification note for exact assignments and remaining listening checks. Numeric waveform checks cannot establish perceived quality or balance.
